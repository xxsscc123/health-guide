# 中医体质健康指南工具 - 快速启动指南

## 📋 项目简介

这是一个基于中医体质学说的健康指南工具，通过舌苔分析和问卷调查，判定用户的体质类型，并提供个性化的调理方案。

**主要功能：**
- 舌苔特征分析
- 30题体质问卷
- 9种体质判定
- 个性化调理方案（饮食、运动、穴位、生活起居）

## 🔧 常见问题

### Q1: 运行 `npm install` 报错？

**解决方案：**
```bash
# 清理缓存
npm cache clean --force

# 重新安装
npm install
```

### Q2: 端口3000被占用？

**解决方案：**
修改 `backend/server.js` 文件，将端口改为其他端口：
```javascript
const PORT = 3001; // 改成3001或其他端口
```

### Q3: 浏览器打开显示空白？

**检查步骤：**
1. 确认服务器是否启动成功
2. 检查浏览器控制台是否有错误（F12打开）
3. 确认访问地址是 `http://localhost:3000`

### Q4: 如何停止服务器？

在命令行窗口按 `Ctrl + C`
